# Archangel Linux test branch

An up-and-coming (hopefully) Archiso-based Linux distro maintained by a person with too much hope.

## Building 
(for Arch)  
``# pacman -S --needed archiso git``  
``~ git clone https://github.com/mewity1816/archangel-linux``  
``~ cd archangel-linux``  
``# mkarchiso -v ./``
